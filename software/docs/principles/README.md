# Principles

Engineering principles for maestro's software. The index, with when each one applies, is in `software/CLAUDE.md`. Each file here holds the full rule and one maestro example of the mistake it prevents.

These are judgment rules. Nothing enforces them automatically. When the same violation keeps coming back and a script can detect it, turn it into a lint and add it to the rules table in `software/CLAUDE.md`.

The rule text is adapted from the principle skills in [pstack](https://github.com/cursor/plugins/tree/main/pstack), MIT licensed. See `LICENSE-pstack`.
